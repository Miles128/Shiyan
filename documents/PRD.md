# 拾言（Shiyan）— Product Requirements Document

## 1. Overview

| Field | Value |
|-------|-------|
| 产品名（对内） | 拾言 |
| 产品名（对外 / 包名） | Shiyan |
| 工程仓库 | Shiyan |
| 平台（当前） | macOS 桌面（Tauri 2） |
| 类型 | 本地优先英语学习 App |
| 主要用户 | 本人：用真实英文新闻学词汇与阅读 |

**一句话：** 自动收录经典英文新闻全文，干净阅读；按需翻译；把生词与短语捡进词库；想读整本时导入公版书。

**定位对照：** 比 LingQ 更轻、本地免费、不啰嗦；不做全媒介 immersion 平台。

## 2. Problem

- LingQ 等产品收费烦、界面重，学习路径被功能淹没。
- 需要**自动找到**可免费阅读的经典新闻，并落到本地全文。
- 需要点词翻译与生词收藏，但翻译默认不要抢戏。

## 3. Goals

1. **自动收录**：精选经典新闻站（RSS 发现 + 摘要不足时抓公开文章页正文）。
2. **干净阅读**：按来源分板块；英文正文为主。列表与阅读页标题保持英文（不做标题翻译，省 token 且避免误导）；标题下必须有 **1–2 句中文简介**（不是英文摘录、不是全文预译）。无 API Key 时简介可空，不得用英文片段冒充。
3. **按需翻译**：全文 / 段落 / 划词；默认隐藏；段落按钮悬停才出现。翻译引擎优先用 macOS 内置系统翻译（离线免费、正文不出本机），系统引擎不可用时自动回退大模型 API；用户可在设置里锁定「仅系统翻译」或「仅 API」。标题简介与生词释义是生成任务，始终走大模型。
4. **按需朗读（TTS）**：单词/划词、段落、全文；系统语音；与翻译入口同级、不抢戏。
5. **生词闭环**：划词入库（释义、词性/类型、搭配、出处句）；生词与短语两库总览与搜索；可标为「已掌握」移出学习列表（可恢复）；可一键导出 CSV（Anki / Excel / Numbers 可读）。
6. **难度标注**：设置 CEFR + 词频双阈值；超出任一标准的词/短语正文下划线；点击看释义并可加入生词库。
7. **正文高亮**：阅读页高亮「学习中」生词；点击可查看释义 / 搭配。
8. **难度档位**：列表按内置词表密度与句长加权给出文章难度分档（简单 / 普通 / 较难 / 困难 / 极难），随 CEFR 与词频设置变化。
9. **本地可控**：SQLite + `config.local.json` 自配 LLM 与难度；无账号。
10. **隐式已读**：打开阅读页即记下 `last_opened_at` / `open_count`（不弹窗、不填表）。
11. **学习分析**：首页行内显示今日 / 本周 / 累计读篇与本周新词；Stats 页显示阅读分钟数、常读来源、生词/短语/已掌握计数；已读条目在列表中弱化。不上传。
12. **卡片中文**：刷新、首页打开后，对缺简介的文章补 `summary_zh`（简介 1–2 句、约 40–120 字）。有 Key 则自动补；无 Key 优雅降级。标题不译中文（见 Goal 2；DB 的 `title_zh` 列仅为免迁移保留，代码零引用）。
13. **兴趣排序**：前端 `src/rank.ts` 打分（确定性规则、可解释、无 ML 运行时）：新鲜度 ×（来源/分类亲和度）+ 显式信号（点赞、停留时长加成、30 秒内跳出弱惩罚、已读完下沉）+ 标题词兴趣画像 + 每日重播种的探索抖动（±0.3，保证未读文章有曝光位）。前端再叠加当前词汇水平的难度适配；「今日推荐」取未读 top 并按分类打散。
14. **词汇测评（Placement）**：内置自适应词汇测评（连续能力值 L）；首次使用引导测评，完成后把结果写入难度默认值；可跳过，之后可重新测评（结果与时间戳存 config）。
15. **短语库**：划词判定短语（词表优先，否则 LLM）；生词与短语统一入库（同一 memory 表，`kind` 区分），短语走专用 enrichment 提示词（含义/习语/短语动词/搭配）。
16. **订阅源管理**：可增删 RSS 源、启用/停用、按分类排序并新增分类；刷新含清理（导航墙、假正文、teaser、链接列表）；长期无新文的源自动停用，不删源、不删已收文章。
17. **公版书（Project Gutenberg）**：设置「书籍」页可本地搜索 Gutenberg 官方目录并一键导入整本；导入后按章节拆成普通文章，阅读、查词、翻译、统计全部复用；书籍与 RSS 在界面上分区，刷新只拉 RSS、永不触碰书章。

## 4. Non-goals（当前阶段硬约束）

- YouTube / 播客 / 视频字幕导入
- 账号、云同步、社区
- 付费墙破解、盗链受保护流媒体
- 大规模无节制全网爬虫
- Windows / iOS 发布（架构可预留）
- 打开文章自动全文预翻译
- 与 LingQ 功能对标竞赛

## 5. 用户流程

### 5.1 刷新与阅读

打开「今日阅读」→ 点刷新 → 进度条显示下载/补简介 → 按 RSS 源分板块浏览（常读来源在上；英文标题 + 一两句中文简介）→ 点进全文阅读（页头同样显示简介）。

### 5.2 翻译、朗读与难词

- 全文翻译开关（按段请求并缓存）
- 翻译引擎：默认「自动」= 优先 macOS 系统翻译，不可用时回退大模型 API；设置里可切「仅系统翻译（正文不出本机）」或「仅大模型 API」
- 全文朗读 / 停止（按段排队，系统 TTS）
- 段旁悬停显示「译」「读」
- 划词浮层可「朗读」当前词/选区
- 设置中的 CEFR + 词频双阈值：超出任一标准的词/词表短语自动下划线
- **单击正文任一英文单词**即可翻译（词表优先，否则 LLM）；划词仍译短语
- 浮层可加入生词库

### 5.3 生词

加入时 LLM 补全释义 / 类型 / 搭配（若已有词表释义则作初值）。生词与短语两个库可分别搜索、翻页；学习中的标为「已掌握」后移出学习列表，也能从「已掌握」恢复；整库可导出 CSV。

### 5.4 公版书

设置 →「书籍」→ 首次使用先下载 Gutenberg 官方目录（约 21 MB，本地镜像后离线可搜）→ 按书名/作者搜索 → 一键导入整本 → 每章成为一篇普通文章，出现在侧栏的书籍段；阅读、查词、翻译、统计与新闻文章完全一致。

## 6. 内容策略

| 原则 | 说明 |
|------|------|
| 免费可读 | 只收录可合法免费阅读的源 |
| 经典新闻优先 | Guardian、BBC World、Al Jazeera、DW、NPR、France 24、UN 等 |
| RSS + 页抓 | RSS 摘要不够则抓公开 HTML 抽正文；疑似付费墙跳过。摘要、整页导航/关键词墙、链接列表不当正文，刷新时清掉 |
| 英文 only | 过滤明显非英文条目 |
| 难度词表 | 内置 CEFR-J + 词频（约 20k）+ 常用短语；本地标注 |
| 公版书 | Project Gutenberg 官方目录 + 官方便携文本；只导入已进入公有领域的作品，目录本地镜像后可离线搜索 |

## 7. 设置

`config.local.json`（gitignore）：`base_url` / `api_key` / `model` / `cefr_level` / `freq_band` / 阅读排版（`reader_font` / `reader_font_size` / `reader_line_height` / `reader_line_width`）/ `translation_provider`（`auto` / `apple` / `api`，默认 `auto`）。示例见 `config.local.json.example`。设置页「大模型」标签页可直接改引擎与 LLM 参数。

默认难度：CEFR **B1** + 词频 **3k**。

默认排版：衬线 Iowan、18px、行距 1.75、行宽随窗口（全宽，左右留边）。

## 8. 技术约束

- Tauri 2 + React + TypeScript + Vite + SQLite
- OpenAI 兼容 `chat/completions`
- 密钥仅存本地配置文件
- macOS 系统翻译走 Apple Translation framework 的无 UI 会话（`init(installedSource:target:)`，需 macOS 26 Tahoe+），且需用户在 系统设置 → 通用 → 语言与地区 → 翻译语言 中安装简体中文与英语；程序无法自行下载该语言包（`canRequestDownloads` 在非 GUI 上下文恒为 false）。旧系统或缺语言包时引擎报「不可用」，按 `translation_provider` 回退 API

## 9. 信息架构

1. 今日阅读（主页）
2. 阅读页
3. 生词库（生词 / 短语 两库，各含学习中与已掌握）
4. 学习分析（Stats）
5. 词汇测评（Placement）
6. 设置（阅读 / RSS / 书籍 / 大模型 / 数据五个标签页）

## 10. 验收标准

- [ ] `pnpm tauri dev` 可在 Mac 打开「拾言」窗口
- [ ] 刷新能从经典新闻源拉到全文（国际分类可见多源板块）；只有简介或整页标签的条目不出现
- [ ] 有 API Key 时：列表每条有 1–2 句中文简介，阅读页页头同样显示；标题保持英文；不得用英文摘录代替简介
- [ ] 无 API Key 时：仍可阅读英文；缺简介处留空或提示去设置，不假装已翻译
- [ ] 阅读页默认无译文；单击单词、划词、悬停段译均可用
- [ ] 阅读页可朗读单词/划词、段落、全文，并可停止
- [ ] 超出难度的词有下划线；点击可看释义并加入生词库
- [ ] 生词可加、可标为已掌握，并能从已掌握恢复
- [ ] 学习中的生词在正文中有高亮，点击可查看释义
- [ ] 列表显示文章难度档位（简单 / 普通 / 较难 / 困难 / 极难），随笔词设置变化
- [ ] 设置可改 CEFR / 词频 / 阅读排版（字体、字号、行距、行宽）并写入 `config.local.json`
- [ ] 打开阅读页后该篇记为已读；回首页该行弱化
- [ ] 兴趣排序生效：常读来源/点赞/长停留的文章排前，已读完下沉，未读文章保探索曝光
- [ ] 词汇测评可完成并把结果写入难度设置；可跳过、可重测
- [ ] 划词判定短语时可入库，与生词同库管理，enrichment 有短语释义
- [ ] 可添加/删除 RSS 源、启用停用、按分类排序并新增分类
- [ ] 设置「书籍」页可下载目录、搜索并导入一本 Gutenberg 书；导入后章节以普通文章出现且刷新不重拉
- [ ] Stats 页可见阅读与词汇统计（读篇/分钟数/常读来源/词库计数）；无记录有空状态
- [ ] 生词库可一键导出 CSV（生词+短语、全部状态；Excel/Numbers/Anki 可读）
- [ ] `pnpm test` 与 `cargo test` 通过

## 11. 成功标准（个人）

连续一周愿意用本 App 读新闻，而不是打开 LingQ；刷新不烦、界面不吵。
